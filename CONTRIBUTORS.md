## 📋 Contribution Levels

### Level 1: Contributor
- 1-5 merged PRs
- Helped with a feature or fix
- Examples: Bug fixes, small features

### Level 2: Regular Contributor  
- 6-20 merged PRs
- Consistent contributions
- Examples: Multiple features, extensive bug fixes

### Level 3: Maintainer
- 20+ merged PRs
- Actively maintains part of codebase
- Reviews and merges PRs
- Examples: Code review, major features

### Level 4: Core Team
- Founding member or key contributor
- Shapes project direction
- Handles releases and versioning
